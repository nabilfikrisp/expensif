## Target vs actual

`open` means the maintainer has not decided which side changes. `target decided` records an explicit maintainer decision; any remaining mismatch requires the implementation to change. Existing target wording alone does not authorize agents to settle a difference or implement a fix.

| Area                         | Target or unresolved question                                                                                                                  | Actual                                                                                               | Decision state | Evidence                                                                                                                            |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Access-token lifetime        | 5-minute target                                                                                                                                | Default is 5 minutes; configuration can override it                                                  | target decided | [Configuration schema](../server/src/pkg/env/index.ts), [token signing](../server/src/modules/auth/service/index.ts)                      |
| Refresh-token lifetime       | 2-hour idle window with a 24-hour absolute cap for web                                                                                         | Defaults are 2 hours idle and 24 hours absolute; cookies are bounded by session expiry.              | target decided | [Configuration schema](../server/src/pkg/env/index.ts), [cookies](../server/src/pkg/cookies/index.ts)                               |
| Validation responses         | Shared error response envelope                                                                   | Validation responses differ from the declared shared envelope                                        | open           | [Shared schema](../server/src/shared/response.schema.ts), [login route](../server/src/modules/auth/controllers/http/login.ts)       |
