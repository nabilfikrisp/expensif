## Target vs actual

`open` means the maintainer has not decided which side changes. `target decided` means an explicit maintainer decision requires the implementation to change. Existing target wording alone does not authorize agents to settle a difference or implement a fix.

| Area                              | Target or unresolved question                                                                                                                  | Actual                                                                                                            | Decision state | Evidence                                                                                                                                                                                                    |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Expense ingestion                 | Resolve linked owner and save immediately                                                                                                      | The expense command parses and displays one object; no linking check or message/expense writes                    | open           | [Bot controller](../server/src/modules/expense/controllers/bot.ts), [service](../server/src/modules/expense/service.ts)                                                                                     |
| Multiple items | Multiple expenses per message | One parsed object | open | [Parser](../server/src/modules/expense/parser.ts) |

| Refresh sessions and logout       | [Current-session logout](product-intent.md#why-a-particular-logout-scope) revokes the associated refresh session; access JWTs expire naturally | Refresh sessions are not tracked; previously issued refresh JWTs remain valid, and logout only clears cookies     | target decided | [Auth service](../server/src/modules/auth/service.ts), [logout controller](../server/src/modules/auth/controllers/http/logout.ts)                                                                           |

These observations are not assigned backlog work. The maintainer chooses which to schedule; scheduled items belong in [backlogs](backlogs/) and receive a link here.

| Gap                                                                                                                           | Evidence                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
